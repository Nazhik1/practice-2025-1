🤖 Telegram-бот «Расписание МосПолитеха»

Бот показывает актуальное расписание занятий для студентов Московского Политеха.

✨ Возможности

  • 📅 Расписание на сегодня (/today)
  • 📆 Расписание на завтра (/tomorrow)
  • 🗓 Расписание на всю неделю (/week)
  • 🔘 Постоянная клавиатура с днями недели (Пн–Сб)
  • 🛡 Защита от истечения токена
  • 🎨 HTML-разметка сообщений

🚀 Быстрый старт

Требования

  • Node.js
  • Токен Telegram-бота от @BotFather
  • Токен API МосПолитеха (из личного кабинета)

Установка

git clone https://github.com/username/mospoly-bot.git
cd mospoly-bot
npm install

Настройка .env

BOT_TOKEN=ваш_токен_от_BotFather
MOSPOLY_TOKEN=ваш_токен_из_ЛК
DEFAULT_GROUP=251-337

Запуск

node bot.js

📋 Команды бота

  • /start — приветствие и клавиатура
  • /today — расписание на сегодня
  • /tomorrow — расписание на завтра
  • /week — расписание на неделю
  • /help — справка

🛠 Технологии

  • Node.js — среда выполнения
  • grammY — Telegram Bot API
  • axios — HTTP-запросы к API МосПолитеха
  • dotenv — хранение токенов
